# Parallel Decision Tree Learning on CPU–GPU Systems

## Project Overview
Implementation of parallel decision tree learning with GPU acceleration for heterogeneous systems.

## Milestones
- **milestone-1**: Sequential decision tree baseline 
- **milestone-2**: GPU-accelerated split finding 
- **milestone-3**: Parallel ensemble learning
